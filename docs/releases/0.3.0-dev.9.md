# GameWarden 0.3.0-dev.9

## Data impact

- **Update only** — instances, worlds, mods and the database stay as they are. No database or data-layout change.

## What changed

This release is the panel review pass: the same features, finished and checked at phone width.

- **Errors are visible:** the dashboard, Settings, Console, Jobs, Info, server resources and the job log show the
  API error with *Retry* instead of an endless skeleton, a blank tab or a false *No output yet*.
- **Phones:** notification destinations and the delivery log become cards with Test, Edit, menu and Retry; jobs keep
  stage, progress and start time; Game API players become cards with their actions. The System and server tabs scroll
  the active tab into view.
- **Settings and logs:** notification saves keep the form open on failure. System log filters live in the URL, and
  *Load older rows* pages through the log.
- **Server actions:** *Update game* asks first and explains the stop, update and restart. Disabled menu items say why.
- **Console:** *Copy* next to *Download*.
- **Info:** the server's folders (game files, world, config, mods, logs).
- **Wizard:** a failed minimum-resource or prerequisite check turns the last button into *Install anyway* and says
  what failed.
- **Agents:** clients show their actual scopes; *Require Admin mode for system writes* is a switch; a token can be
  rotated; diagnostics can run up to 480 minutes.
- **Keyboard and palette:** job logs and config files open from a real button; **Ctrl/⌘ K** has *Check for updates*;
  **g d** opens the dashboard and **g s** opens System.
- **Smaller fixes:** one `h1` per page, 40 px header controls, Vietnamese labels for the remaining English strings,
  and a fresher mock (Core `0.3.0-dev.8`, Valheim `0.5.1`) with screenshots for every screen.

No Core or adapter change; Valheim stays at 0.5.1.

  shows the error and *Retry*.

- [ ] Open **System → Logs**, choose a level, reload: the filter is still there. *Load older rows* adds the next page.
- [ ] Open a server → **Console**: *Copy* copies the visible log.
- [ ] From the server menu choose *Update game*: the confirmation explains the restart.
- [ ] Open **Info**: the folder paths match `C:\GameWarden\instances\<id>\…`.
- [ ] Create a server on a VM below the minimum: the last button says *Install anyway* and the reason is visible.
- [ ] Open **System → Agents**: scopes are listed; toggle *Require Admin mode*; rotate a token.
