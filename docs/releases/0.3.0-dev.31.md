# GameWarden 0.3.0-dev.31

## Data impact

- [x] **Update only** — instances, worlds, mods and the database stay as they are.

## What changed

- **Activity is a top-level destination** ([ADR-0035](../../decisions/0035-task-first-navigation-activity-and-phone-bottom-bar.md)):
  the feed and its server/type filters moved from System to `/activity`. Old `/system/activity` links and bookmarks
  redirect with the same filters.
- **Phones get a four-item bottom bar** — Dashboard, Servers, Activity, System — with icon and label, an active
  state and safe-area padding. The hamburger drawer is gone; the server quick list stays on the Servers page.
- **System tabs are ordered by use:** Overview · Jobs · Logs · Notifications · Agents · Operations · Adapters.
  Jobs stays a System tab and keeps its one-action header shortcut; it was not promoted, because the header
  already opens it in one action.
- Desktop keeps the 248 px sidebar with the same four destinations and the server list.
- **Measured on a phone** from a server page: Dashboard, Servers and System went from two actions to one; Activity
  from four actions to one. The B-lite option and the measurement are in ADR-0035.
- This release also contains the panel UX pass first shipped in dev.30 (Batch 1–3: section pickers, states, one time
  format, unsaved guards, onboarding, wizard and Agent dialog, console and notification polish).
