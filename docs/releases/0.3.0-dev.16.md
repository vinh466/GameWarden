# GameWarden 0.3.0-dev.16

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Test Discord chooses the channel.** A **Test channel** select lists every configured mapping (`system` and each
  server), so the test does not silently keep using an old `system` channel after you changed a server channel.
- **Unsaved changes are obvious.** When the form differs from the saved settings, the screen says Test uses the saved
  configuration; press **Save** first.
- **Unknown channel is explained.** If the bot cannot see the id at all, the Channel row says it cannot see the
  channel in the configured guild and to check the id and the bot's View Channel permission. A category/voice/forum
  still names its actual type.
- The test endpoint accepts an optional `channelId`, defaulting to `system` or the first mapping.

## What to test on the VM

- [ ] Change a server channel, press **Save**, choose it in **Test channel**, press **Test Discord**: the message
  arrives in that exact channel.
- [ ] Change a field without saving: the yellow “unsaved changes” notice appears, and Test uses the saved value.
- [ ] Use the old/deleted channel id: the Channel row says the bot cannot see it.
- [ ] Use a category/voice/forum id: the Channel row names the actual type.

## After updating

- [ ] Server list still shows the instances and they start.
- [ ] The worlds are the expected ones.
- [ ] The panel opens on the dashboard; System shows the same version and update state as before.
