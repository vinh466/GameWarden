# GameWarden 0.3.0-dev.7

## Data impact

- **From `v0.3.0-dev.4` or newer:** update only. No database change.
- **From `v0.3.0-dev.3` or older:** update only; the `notification_status` table from dev.4 is added on first start.
- **From `v0.2.0-rc.19` or older:** back up before updating. The observability migration landed in `v0.2.0-rc.20`.

`v0.3.0-dev.6` was tagged but not published; this release contains the same panel work plus the fixes below.

## What changed

- **Panel:** System is now the operations hub. Jobs, Activity, Adapters and Agents moved from the sidebar into
  System tabs: **Overview**, **Jobs**, **Activity**, **Adapters**, **Agents**, **Logs** and **Notifications**.
  Each tab has its own URL; the old `/jobs`, `/activity`, `/adapters` and `/agents` links redirect and keep their
  filters.
- **Panel:** every System tab now shares one layout: a short description, its actions on the right, then one table
  or card, with loading, empty and error states.
- **Panel:** phones get readable lists for jobs, logs and the Agent audit, the log filters move into a drawer, and
  the active System tab scrolls into view.
- **Panel:** the notification destination list is a table with one action menu; deleting a destination or revoking
  an Agent token asks first, and the Agents and Notifications tabs no longer show blank tables while loading.
- **Panel:** the notification form stacks its fields on phones, and the help drawers and option descriptions from
  dev.5 stay inside the Notifications tab.
- **Panel:** the development mock now answers the Agent and notification endpoints with sample data.
- **Release:** the "tag is on main" check now fetches full history, so a release still works after `main` moves on.

No Core, adapter or data changes.
