# GameWarden 0.3.0-dev.30

## Data impact

- [x] **Update only** — instances, worlds, mods and the database stay as they are.

## What changed

This release is the panel UX pass of [22](../22-panel-ux-review.md), plus one CLI resource fix.

- **Phones have a section picker** instead of a scrolling tab strip on System and on a server page; desktop keeps
  the tabs.
- **Every data view has loading, empty and error states:** the wizard (game picker, Review), server Overview recent
  jobs, the phone Jobs list, the console, the dashboard numbers, the Operations sub-cards and the Navbar server
  list.
- **One time format:** `RelativeTime` reads "3 minutes ago" under 24 hours and the locale date and time after that,
  with the exact ISO value in the tooltip. It is used by activity, jobs, mods, configs, notifications, traces,
  incidents, model calls, agents, audit, logs and the update card.
- **Unsaved changes are guarded:** Settings, Operations and the config editor (including closing its Drawer) ask
  before leaving; switching config tabs keeps the draft. The Agent token copy now names the machine that runs the
  Agent client.
- **Dashboard:** a "Now" line answers "is everything okay?" first, the phone order is Now → attention → servers →
  numbers → activity, and a fresh install gets a dismissible **Getting started** card instead of five zero cards.
- **Servers:** phone cards keep the full state word and show CPU/RAM; the desktop table has a Resources column;
  Info is a definition list with copy buttons; Mods and Config files are cards on phones; the Game API player
  actions are a worded menu; Settings has a section navigator and one-sentence warnings with the full text in help.
- **System:** Operations is split into Setup and Agent activity, model calls and traces are cards on phones, and
  Notifications has a dismissible pin hint, a collapsible preview, last-delivery time and a destination Drawer on
  phones.
- **First run and Agent setup:** the wizard game picker is a radio group with a real selected state, the Agent
  permission picker uses preset cards with counts and no nested scrolling, and the console has a Ctrl/⌘ F search
  hint plus a visible disabled reason.
- **Refactor:** the Operations, Notification destination and Mod set screens are split under the panel's 200-line
  rule; an unused `clsx` dependency and five dead i18n keys are gone; the CLI disposes its `HttpRequestMessage`
  (CA2000).

- [ ] Update from the panel; the release notes say **Update only**, and the update finishes and reconnects.
- [ ] Desktop: the System tabs and a server's tabs still navigate; the dashboard shows the Now line; Settings,
  Operations and the destination form look unchanged in their desktop layouts.
- [ ] Phone (or a narrow window): System and a server use the **Section** picker; the dashboard leads with Now; the
  server cards, Mods, Config files, model calls and traces are readable without horizontal scrolling.
- [ ] Edit a setting, then open Dashboard: the **unsaved changes** dialog appears (Keep editing / Leave without
  saving). Do the same in the config Drawer, then close the Drawer.
- [ ] New server: pick a game (the card shows a selected state and the radio responds to arrow keys); Next without
  a game shows "Choose a game to continue." The rest of the wizard installs as before.
- [ ] System → Agents → Create agent: the preset cards show counts; changing a permission switches to Custom; the
  permissions list scrolls only with the dialog.
- [ ] Console: Ctrl/⌘ F focuses search; a stopped server shows why the command field is disabled.
- [ ] System → Notifications on a phone: Add destination opens a full-height Drawer with Cancel/Save always visible.
- [ ] Existing servers start, the worlds load, mods load and Discord answers.
