# GameWarden 0.3.0-dev.23

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Kill switch covers old buttons.** After `/agent-off`, an approval or incident button that is still visible no longer
  executes a write; it answers that the Agent is off and to use `/agent-on`.
- **Incident engine respects the switch.** While the Agent is off, activity no longer creates incident cards or
  posts to Discord. The webhook notification path is unchanged.
- Tests enable the Agent explicitly before exercising the incident engine.

## What to test on the VM

- [ ] `/agent-off`, then press an old approval button or an incident **Restart** button: it is refused with the
  “Agent is off” message.
- [ ] `/agent-on`, then repeat: the button works again.
- [ ] While off, crash/restart a test server: no new incident card is posted by the bot (webhook alerts, if
  configured, still arrive).
- [ ] While on, a crash still creates the incident card and thread.

## After updating

- [ ] Server list still shows the instances and they start.
- [ ] The worlds are the expected ones.
- [ ] The panel opens on the dashboard; System shows the same version and update state as before.
