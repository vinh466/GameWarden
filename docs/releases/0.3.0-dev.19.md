# GameWarden 0.3.0-dev.19

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Fix:** slash commands threw `NullReferenceException` in `Target(ISocketMessageChannel)` because
  `SocketSlashCommand.Channel` can be null. The bot now resolves the target from `command.ChannelId`, so
  `/status`, `/ask`, `/server`, `/logs` and `/diagnose` work.
- **Debugging:** the bot logs each slash command (name, user, channel) and why a message was ignored (channel not
  mapped, bot not mentioned, user not in the allowlist).
- Approvals for a slash-command write use the resolved channel when `command.Channel` is null.

## What to test on the VM

- [ ] `/status`, `/server`, `/logs`, `/diagnose` in a mapped channel.

- [ ] Turn **Require a mention** on and send without a mention: ignored, with a debug log.
- [ ] Send from a user not in the allowlist: ignored (or a permission reply when mentioned), with an info log.
