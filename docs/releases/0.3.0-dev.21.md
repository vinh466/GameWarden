# GameWarden 0.3.0-dev.21

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Mods questions have tools.** `list_mods` returns the instance's loader, active/previous/pending mod sets, the
  enabled flag of every entry, the share code and whether a restart is required. `get_mod_log` reads the loader log
  (`BepInEx/LogOutput.log`) in the running set.
- **File discovery.** `list_files` lists the instance root or a subfolder (up to 500 entries) so the Agent no longer
  guesses a path. `read_file` no longer shows `server/BepInEx/LogOutput.log` as its example, which the model copied
  literally.
- **Tool errors no longer end the answer.** A missing file (`AgentRequestException`) is returned to the model as a
  tool error instead of escaping to Discord as `Lỗi: …`; the prompt tells the model to use `list_mods`/`get_mod_log`
  for mods and `list_files` before reading an unknown path.
