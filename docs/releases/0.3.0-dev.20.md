# GameWarden 0.3.0-dev.20

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Fix:** the second `command.Channel.Id` in `AskAsync` made every slash command throw `NullReferenceException` after
  the channel lookup was fixed. The runtime now receives `command.ChannelId`.
- **Fix:** Core ran with invariant globalization. Discord.Net creates the guild's preferred culture (for example
  `en-US`) in `SocketGuild.Update`, so the globalisation mode threw `CultureNotFoundException`, aborted the guild
  update and left the bot with no channels. Core now uses the normal culture data; the CLI, Setup and MCP stay
  invariant.
- No other behaviour change.
