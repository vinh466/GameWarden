# GameWarden 0.3.0-dev.27

## Data impact

- **Update only** — no database migration.
- Eval results are kept in `agent-evals.json` in the data root (latest 20 runs). The file is written atomically and is
  safe to delete.

## What changed

- **Agent API evals.** The scoped Agent surface can now run and read the golden eval suite:
  - `GET /api/v1/agent/evals`
  - `POST /api/v1/agent/evals/run?id=`
  - `GET /api/v1/agent/evals/last`
  - `GET /api/v1/agent/evals/history?limit=10`
- **Persistence.** Every eval run is saved to `agent-evals.json`; the last 20 runs are kept. The suite still uses fake
  tools and never touches a real server.
- **Serialised runs.** A second eval request waits for the current one instead of starting a parallel model run.
- **Docs:** the Agent API list in `docs/15` now includes the eval endpoints.
