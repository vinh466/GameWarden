# GameWarden 0.3.0-dev.18

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **Fixed:** the Operations panel rounded 64-bit Discord channel ids through a JavaScript number. Pasting
  `1567753071566524496` became `1567753071566524400`. Channel ids now stay strings from the input to
  `agent-host.json`.
- **Restart Core from the panel:** a **Restart Core** button in System → Operations confirms first, warns about
  unsaved changes, and refuses while a job is running. On the Windows service a detached helper waits for Core to
  stop, then starts the service again; game servers keep running. Development and Linux answer with a clear 409.
- Dev.17's `/api/v1/agent/operations` and Discord test logging are included.

## What to test on the VM

- [ ] Paste a real channel id with 18–19 digits into every channel field, Save, reload: the last digits are unchanged.
- [ ] Press **Test Discord** with the channel chosen: the message arrives and the Channel id row shows the exact id.
- [ ] Press **Restart Core**: confirm; the panel loses Core for a few seconds, reconnects, and the servers keep
  running.
- [ ] Start a job, then press **Restart Core**: it refuses with “A job is running”.
