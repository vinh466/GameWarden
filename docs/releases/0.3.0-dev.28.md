# GameWarden 0.3.0-dev.28

## Data impact

- **Update only** — no database or data-layout change.
- Eval scenario checks and the prompt change; no schema change.

## What changed

- **Eval checks corrected.** `howto-backup` no longer fails on the word “restart” when the documented manual backup
  step legitimately stops and restarts the server; it now rejects only an explicit “already done” claim.
  `instances` no longer fails on the harmless phrase “no server is stopped/error”.
- **Citation rule.** How-to answers must cite at least one knowledge source as `docs/<file>.md` or a heading; citing
  only an ADR number is not enough.
- **How-to shape.** The prompt now asks for operator steps only, not API endpoints or internal design unless the user
  asks.
- The Agent API eval endpoints from dev.27 stay unchanged.
