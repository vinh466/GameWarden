# GameWarden 0.3.0-dev.10

## Data impact

- **Update only** — instances, worlds, mods and the database stay as they are. No database or data-layout change.

## What changed

The three items left from the panel review:

- **Info → Launch summary:** the command line the server starts with, with every secret replaced by `<secret>`.
  Core builds it from the adapter and the instance's settings; the secret value never leaves the secret store.
- **System → Logs:** the table is virtualised, so a full page of 100–500 rows scrolls without rendering every row.
  The filters stay in the URL, and *Load older rows* still pages through the log.
- **System → Notifications:** a **Status message preview** card shows what a destination in `status` mode edits in
  place, whenever a status destination exists.

No adapter change; Valheim stays at 0.5.1.

## What to test on the VM

- [ ] Open a server → **Info**: *Launch summary* matches its start command; the password shows as `<secret>`.
- [ ] Open **System → Logs**, scroll the table: rows appear as you scroll, the header stays, and filters still work.
- [ ] Add or open a destination with mode **Status**: the preview shows one line per server. Edit the message on
  a phone; the preview wraps instead of overflowing.
