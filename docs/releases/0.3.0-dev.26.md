# GameWarden 0.3.0-dev.26

## Data impact

- **Update only** — no schema change.
- The package adds `evals/*.json` (golden scenarios). Feedback votes are stored as `feedback.up` / `feedback.down`
  rows in the existing `agent_events` table.

## What changed

- **Golden scenarios.** Six built-in scenarios (`status`, `mods`, `howto-backup`, `crash-triage`,
  `write-approval`, `instances`) run against the configured model with **fake tools**. They never touch a real
  server, job, file or secret.
- **Quality check card.** System → Operations → **Quality check** runs the scenarios on demand and shows pass/fail,
  score, tools used, the answer and every check. `GET /api/v1/system/agent-host/evals` lists them;
  `POST /api/v1/system/agent-host/evals/run` runs all or one `?id=`.
- **Feedback loop.** Every mention reply now carries 👍/👎 buttons. A vote is recorded as an Agent event linked to the
  run id, so it appears in the trace explorer and can be aggregated later.
- **Docs:** `docs/21` records the eval/feedback loop.
