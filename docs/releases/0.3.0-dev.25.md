# GameWarden 0.3.0-dev.25

## Data impact

- **Update only** — no database migration.
- The package now includes the operator docs under `knowledge/` for the Agent's local knowledge search. They are the
  same public docs as the repository; no secrets.

## What changed

- **Trace explorer.** System → Operations has a **Recent traces** card. Opening a trace merges model calls, tool calls,
  policy decisions, approvals, agent events and incidents into one chronological timeline, with the redacted
  request/response for each model call.
- **Knowledge for Q&A.** New `search_knowledge` tool searches the shipped docs, adapter guides and runbooks locally.
  The model is instructed to call it for how-to/concept/process questions and cite the source (file/heading).
- **Prompt v3.** The prompt now has a tool-routing table, a `conclusion → evidence → next step` answer shape, a
  no-invented-numbers rule, a "no repeated identical tool calls" rule and an explicit "say when evidence is
  incomplete" rule.
- **Tool output cap.** A capability result is capped at 12,000 characters (redacted) with a note to ask a narrower
  query, keeping the model context focused.
- **Loop guard.** The runtime refuses a third identical tool call with the same arguments and tells the model to use
  the evidence it already has.
- **Docs.** `docs/21` records the knowledge/trace/prompt additions; release notes.
