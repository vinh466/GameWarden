# GameWarden 0.3.0-dev.29



## Data impact

- [x] **Update only** — instances, worlds, mods and the database stay as they are.

## What changed

- **A stop can no longer stay in Stopping forever** ([ADR-0034](../../decisions/0034-bounded-stop-and-a-runner-kill.md)).
  After the adapter's stop timeout Core asks the Runner to kill the game tree; ten seconds later the Core watchdog
  kills the Runner, and its Job Object ends the game. The watchdog runs outside the instance queue, so a hung
  Runner request cannot block the panel.
- **Force stop** as the primary action while the server is `Stopping`, behind a confirmation that warns about
  unsaved progress; it sends `stop?force=true`. The API and the Agent stop accept the same `force`.
- **Runner requests time out after 10 s**; a lost Runner is treated as lost instead of blocking the actor.
- **The Runner verifies its kill** (`HasExited` after 5 s), records the exit in a `finally` even when the exit
  event was missed, and writes a stop heartbeat every 5 s.
- **One operation id** (`op_<8 hex>`) is carried through the Core log, the Runner log and the console `GW` lines;
  the snapshot exposes `operationId`, `stoppingSince`, `hardKillAt` and `stopPhase`.
- **The panel shows** `Stopping for N s` and the hard-kill time in the server header.
- **Diagnostics read live logs**: `source=instance` is the dated Runner console (the `GW` lines, not the game's own
  log), files are opened with `FileShare.ReadWrite`, and a bundle includes `console.log`, `runner.log`,
  `runner.previous.log` and the instance's `system.log`. The Runner log rotates at 10 MB with one previous file.
- The Valheim adapter's `stop` is the same; the fix is in Core, the Runner and the Agent.

- [ ] The server list and both instances still show; start `valheim-main` and check the world.
- [ ] **Normal stop:** Stop; the world saves, the state reaches Stopped, and the next start works.
- [ ] **Force stop:** while Stopping, open the actions menu → **Force stop** → confirm. The panel reaches Stopped

  seconds; Core kills the Runner and the panel reaches Stopped without Task Manager. The system log,
  `C:\GameWarden\instances\valheim-main\logs\runner\runner.log` and
  `C:\GameWarden\instances\valheim-main\logs\<date>.log` share one `op_` id.

  Runner is running.
