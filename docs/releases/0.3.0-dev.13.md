# GameWarden 0.3.0-dev.13

## Data impact

- **Update only** — no database or data-layout change.

## What changed

- **System → Operations:** **Save & test model** sends one small chat completion with the saved base URL, model and
  key, and shows the reply and latency. **Save & test Discord** sends one real message through the saved bot token
  and the `system` channel, using Discord's REST API, so it works before the bot is enabled or restarted.
- Both buttons save the form first, so the test uses exactly what is on screen. They remain disabled with a visible
  reason until the model key / bot token and a channel exist.
- New API: `POST /api/v1/system/agent-host/test-model` and `POST /api/v1/system/agent-host/test-discord`.

## What to test on the VM

- [ ] Fill base URL, model and key → **Save & test model**: an answer with latency, or the model's error.
- [ ] Save the bot token and a system channel → **Save & test Discord**: a test message appears in the channel.
- [ ] Remove the system channel and test again: the button says a channel is needed.
- [ ] Turn the Agent off, restart Core, test Discord again: REST still verifies the token and channel.
