# GameWarden 0.3.0-dev.6

## Data impact

- **From `v0.3.0-dev.5` or newer:** update only. No database change.
- **From `v0.3.0-dev.4` or older:** update only; the `notification_status` table from dev.4 is added on first start.
- **From `v0.2.0-rc.19` or older:** back up before updating.

## What changed

- The notification destination form now stacks its fields at phone width instead of squeezing two or three
  columns into the modal.
- Keeps the help drawers and dropdown descriptions added in `v0.3.0-dev.5`.
- No backend or database change.

## What to test on the VM

- [ ] Open **System → Notifications → Add destination** on a phone-width window: every field is full width,
  labels are not clipped and the modal scrolls vertically.
- [ ] Open the `?` beside Mode, Topics and Servers; the help drawer opens and the related links work.
- [ ] Open the Mode, Language and Minimum severity dropdowns; each option shows its description.
- [ ] Save a destination, press Test and confirm the delivery log still works.

## After updating

- [ ] Destinations and delivery history are still there.
- [ ] `gamewarden update --check` says the running version is current.
