# GameWarden 0.3.0-dev.8

## Data impact

- **Update only** — instances, worlds, mods and the database stay as they are. No database or data-layout change.

## What changed

- **Valheim (adapter 0.5.1):** the *Difficulty preset* field now warns that **Hardcore** and **Immersive** turn
  the map off as part of the preset, and that the *No map* switch cannot turn it back on — pick another preset to
  get the map back.
- The preset descriptions and the *No map* help topic say the same, so the panel and the drawer agree.
- **Docs:** the panel and explanation documents record the new warning.

No Core, panel or data changes.

## What to test on the VM

- [ ] Open a Valheim server → **Settings** → *Difficulty preset*: the warning shows under the field in the
  language the panel uses (English and Vietnamese).
- [ ] Choose **Hardcore** or **Immersive**, save and restart: the command line has `-preset hardcore` (or
  `-preset immersive`) and the game has no map.
- [ ] With such a preset saved, turn *No map* off and restart: the map is still off. Choose **Normal** (or another
  preset), save and restart: the map is back.
- [ ] Open the help drawer for *Difficulty preset* and *No map*: the new explanation is there.

## After updating

- [ ] Server list still shows the instances and they start.
- [ ] The worlds are the expected ones.
- [ ] The Valheim adapter shows version `0.5.1` under **System → Adapters**.
