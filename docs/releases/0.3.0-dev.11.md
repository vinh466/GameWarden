# GameWarden 0.3.0-dev.11

## Data impact

- **Update only** — instances, worlds, mods and the existing database stay as they are. This release adds the
  `agent_conversations`, `agent_messages`, `agent_runs`, `agent_tool_calls` and `agent_approvals` tables on first
  start; no existing row changes.

## What changed

The first version of the Owner's **Operations Agent** inside Core ([20](../20-operations-agent.md), ADR-0030/0031):

- **Discord bot** over the Gateway: one channel per server plus a `system` channel, mention chat and slash commands
  (`/ask`, `/status`, `/server`, `/logs`, `/diagnose`, `/approve`, `/deny`, `/stop`, `/start`).
- **Read tools**: status, instances, instance, console, settings, jobs, job log, logs, system-log query, activity,
  metrics, diagnostics and file reads.
- **Write tools**: start/stop/restart, console, install/update. Every write posts Approve/Deny buttons and waits for
  an allowed Owner; approvals expire and are one-shot.
- **Model**: OpenAI-compatible chat completions with tool calling; the base URL, model, limits and API key are
  settings/secrets. Vietnamese is the default language.
- **Audit**: conversations, runs, tool calls and approvals are in SQLite; model and tool output is redacted.
- **CLI**: `gamewarden agent-host status|enable|disable|set|secret` sets the bot, model and channel mapping.

No adapter change; Valheim stays at 0.5.1.

## Discord setup

1. Create the bot in the Discord Developer Portal, enable **Message Content Intent**, and invite it with `bot` and
   `applications.commands`.
2. Copy the guild id and one channel id per server (Developer Mode → Copy ID).
3. On the VM:
   ```powershell
   gamewarden agent-host secret discord-bot-token
   gamewarden agent-host set --guild <guild-id> --channel valheim-main=<channel-id> --channel system=<channel-id>
   gamewarden agent-host secret model-api-key
   gamewarden agent-host set --base-url <openai-compatible-base-url> --model <model-id> --language vi
   gamewarden agent-host enable
   ```
4. Restart `GameWardenCore` (the bot connects at Core start).
5. `gamewarden agent-host status` should show the model, bot token, connection and channels.

## What to test on the VM

- [ ] In a server channel, mention the bot with “kiểm tra server này”; it answers with state/jobs.
- [ ] Ask it to read the last console lines and the last failed job log.
- [ ] Ask it to restart the server: an Approve/Deny message appears; Approve restarts it, Deny does nothing.
- [ ] Try a second Approve on the same message: it is refused (one-shot).
- [ ] Press `/stop`; the next mention is refused until `/start`.
- [ ] Check System → Logs and the `agent_*` tables for the run, tool calls and approval rows.
